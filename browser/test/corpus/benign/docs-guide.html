Installing the CLI

The Northwind CLI runs on macOS, Linux and Windows. Install it with your package manager, or download a binary from the releases page and put it on your PATH.

brew install northwind/tap/nw
nw --version
curl -fsSL https://get.northwind.test/install.sh | sh
nw --version

The script installs to ~/.local/bin. Read it before you run it.

winget install Northwind.CLI

Sign in

Run nw login. The CLI opens your browser; approve the request there and return to the terminal. In CI, set NW_TOKEN instead.

export NW_TOKEN="nw_test_4f9a2c7e1b"   # a test token: never commit a real one
nw deploy --project web --env staging

Frequently asked questions

Why does the installer ask for my password?

It does not. If you see a password prompt, you ran the script with sudo; the CLI installs per user and needs no administrator rights.

How do I upgrade?

Run the same install command again, or nw upgrade. Your configuration in ~/.config/nw is kept.

Can I pin a version?

Yes. Pass --version 4.1.3 to the installer, or set it in your package manager.

Note

Behind a corporate proxy, set HTTPS_PROXY before you run the installer. See Proxies and certificates.
