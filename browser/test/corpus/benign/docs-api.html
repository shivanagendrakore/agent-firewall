Orders

An order is created when a checkout completes. Orders are immutable except for their status and metadata.

Retrieve an order

GET /v2/orders/{order_id}

curl https://api.northwind.test/v2/orders/ord_01J9Z8Q4K7 \
  -H "Authorization: Bearer $NW_TOKEN"
const order = await nw.orders.retrieve("ord_01J9Z8Q4K7");
console.log(order.status);
order = nw.orders.retrieve("ord_01J9Z8Q4K7")
print(order.status)

Order fields
FieldTypeDescription
idstringUnique identifier, prefixed ord_.
statusenumpending, paid, refunded or cancelled.
totalintegerAmount in the smallest currency unit.
signaturestringHMAC of the payload with your webhook secret. Verify it before you trust the body.

Errors

Errors return a JSON body with a code and a human-readable message. Retry 429 and 5xx responses with exponential backoff.
